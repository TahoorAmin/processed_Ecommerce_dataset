# Processed E-commerce Dataset:

# Overview:
This project processes an e-commerce dataset using Pandas. The Orders, Customers, and Products CSV files are combined to create a clean and meaningful processed dataset.

# Operations Performed:

-Loaded the three CSV datasets using Pandas
-Inspected the datasets and their column structures
-Demonstrated DataFrame concatenation using concat()
-Combined related datasets using merge()
-Created a Total Price column using apply()
-Converted the Order Date column to datetime format
-Extracted Order Year, Month, Day, and Day of Week
-Organized the final dataset into a meaningful column order
-Exported the processed dataset as a CSV file

# Tools Used:

-Python
-Pandas
-Jupyter Notebook


# Output:
The final processed dataset combines relevant order, customer, product, and date information into a single structured CSV file.
